A: Positive test result
B: Having the disease


1. *"3% of people actually have this predisposition"*
   P(B) = 0.03
2. *"The genetic test is 99% accurate if a person actually has the predisposition"*
   This means that if the person has the predisposition, there is a 99% chance the test gives positive. Thus,
   P(A | B) = 0.99
   P(A and B) = 0.99 x P(B)
   P(A and B) = 0.99 x 0.03 = 0.0297
3. *"The test is 98% accurate if a person does not have the predisposition"*
   This means that if the person doesn't have the predisposition, there is a 98% chance the test gives negative. Thus,
   P(A^c | B^c) = 0.98
   This also means, there is a 2% chance that the test gives positive even if the person doesn't have the predisposition. Mathematically,
   P(A | B^c) = 0.02
   P(A and B^c) = 0.02 x P(B^c)
   P(A and B^c) = 0.02 x 0.97 = 0.0194

We need to find 
P(B | A) 
= P(B and A)/P(A)
= P(B and A) / (P(A and B) + P(A and B^c))
= 0.0297 / (0.0297  + 0.0194)
= 0.6048879837
