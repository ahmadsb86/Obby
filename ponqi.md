Here are the Minecraft 1.8.9 `/give` commands for each item. Blue = data value **11** for stained clay.

---

**Iron Sword**

```
/give @p iron_sword 1
```

---

**Bow with Infinity I**

```
/give @p bow 1 0 {ench:[{id:51,lvl:1}]}
```

---

**Diamond Pickaxe with Efficiency III**

```
/give @p diamond_pickaxe 1 0 {ench:[{id:32,lvl:3}]}
```

---

**Blue Stained Clay x64**

```
/give @p stained_hardened_clay 64 11
```

---

**Golden Apple x8**

```
/give @p golden_apple 8
```

---

**Arrow x1**

```
/give @p arrow 1
```

---

**Notes:**

- Enchantment IDs: `51` = Infinity, `32` = Efficiency
- Blue stained clay uses data value `11`
- These are all for the nearest player (`@p`). Swap for a username if needed
