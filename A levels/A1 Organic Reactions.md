# Alkanes
1. Combustion    
2. Halogenation via free radical sub (UV light)
3. Cracking (500 deg, zeolite catalyst)
# Alkenes
1. Hydrogenation (150 deg, Ni/palladeium catalyst)
2. Hydration (330 deg, 60 atm, H3PO4 catalyst)
3. Halogenation (Dark)
4. Hydrogen Halide
5. Oxidation w/ cold and dilute KMnO4 to produce diols
6. Oxidation w/ hot and conc. KMnO4
7. Addition Polymerization (60 deg, few atm, Ziegler-Natta)
# Halogenoalkanes
1. Nucleophilic sub w/ OH- AKA hydrolysis (heat under reflux)  
2. Nucleophilic sub w/ CN-  (heat under reflux, in ethanol)
3. 2-stage Nucleophilic sub w/ NH3 (heat in sealed tube, in ethanol) 
4. Elimination (heat under reflux, NaOH in in ethanol) → H2O + Br-
5. Checking halogen $NaOH$ + heat + dil. $HNO_{3}$ + $AgNO_{3}$ --> Silver Halide 
# Alcohols  
1. Combustion
2. Dehydration (170 deg, excess conc. H2SO4, Al2O3) → H2O 
3. Reaction w/ Metals → H2
4. Halogenation via HX produced in situ (heat) → H2O 
5. Halogenation via PCl5 → POCl3 + HCl
6. Halogenation via PCl3 (heat under reflux) → H3PO4
7. Halogenation via SOCl2 →  SO2 + HCl
8. Oxidation w/ KMNO4 / K2Cr2O7 (heat under reflux) → H2O
9. Esterification (heat under reflux, conc. H2SO4)
# Carbonyls
1. Combustion
2. Reduction via LiAlH4 (dry ether)  / NaBH4 (in aq alcoholic)
3. Oxidation (Alcohol #7)
4. Nucleophilic sub w/ Hydrogen Cyanide (NaCN + H2SO4 used because direct HCN toxic)
5. 2,4-DNPH/Brady's → Orange ppt. on all C=O (except carboxylic acid) + H2O
6. Tollens (water bath) → Silver mirror on aldehyde (2Ag) + 4NH3 + 2H2O + acid
7. Fehling's (water bath) → Red ppt. on aldehyde (Cu2O + 3H2O) + acid
8. Iodoform → yellow crystals of iodoform on CH3CO (methyl carbonyl / sec alcohol but not ethanoic acid)  
# Carboxylic Acids / Esters
1. Acid-Base reactions
2. Esterification (Alcohols #8)
3. Reduction (Carbonyls #2 but NaBH4 not strong enough)
4. Acidic Hydrolysis of esters → alcohol +  acid
5. Alkali Hydrolysis of esters → alcohol + salt
6. Chlorination (Alcohols #5)
7. Hydroxy Carboxylic acid self esterification (heat, conc. H2SO4)
# Nitriles
 *In both reactions, cation bonds with expelled halogen*
1. Acidic Hydrolysis (heat under reflux) → Carboxylic Acid + NH4+
2. Alkaline Hydrolysis (heat under reflux) → Carboxylic Base + NH3
