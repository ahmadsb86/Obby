# Benzene
1. Halogenation ($AlX_3$ catalyst, rtp) → $H^+$  (Catalyst routes thru $AlX_4^-$) 
2. Nitration (conc. $HNO_{3}$ + conc $H_{2}SO_{4}$ + 55 deg) → (Catalyst routes thru $HSO_{4}^- + H_{2}O$) $H_{2}O$
	1. Further nitration @ 3,5 with >60 deg
3. Friedal Crafts Alkylation/Acylation w/ Sidechain-$Cl$ + $AlCl_{3}$ + heat → $HCl$
4. Hydrogenation ($Ni$, 150 deg) 
# Methylbenzene
1. Halogenation (dark) (Benzene #1) → two isomers
2. Nitration (30 deg) (Benzene #2) → two isomers
3. Friedal Crafts Alkylation/Acylation (Benzene #3)
4. Free Radical Sub w/ Halogen (UV) → $HCl$
5. Oxidation w/ $KMnO_{4}$ (dil $H_{2}SO_{4}$ to protnate in the end + heat) → -$COOH$ group
# Phenols
1. Acid reactions (only $Na, NaOH$ not $NaHCO_{3},Na_{2}CO_{3}$)
2. Condensation Reaction w/ Acyl Chlorides ($NaOH$ to make phenoxide ion) → Ester 
3. Halogenation (milder conditions) → 2,4,6-triXphenol (white ppt.) + $HX$
4. Nitration w/ dil. $HNO_{3}$ ONLY (milder conditions) → two isomers + $H_{2}O$
# Phenylamine
1. Formation: Nitrobenzene + tin + conc $HCl$ + heat under reflux + in the end dil $NaOH$ → $H_{2}O$
2. Base reactions (weaker than ethylamine and ammonia)
3. Condensation Reaction w/ Acyl Chlorides (No conditions) → Subsituted Amide + $HCl$
4. Diazonium salt formation w/ $HNO_{2}$ (**NITROUS ACID**) or $NaNO_{2}+HCl$ (5 deg w.b.) → $H_{2}O$
5. Diazonium salt + $H_{2}O$ + heat → phenol + $N_{2} + HCl$
6. Diazonium Salt + phenol/phenylamine ($NaOH$)→ Azo Dye
# Acyl Chlorides
1. Formation: (Ditto Alcohols #5)
2. Hydrolysis (Akin to halogenoalkane electrophilic sub of $OH^-$) → Carboxylic acid + $HCl$
3. Condensation Esterification w/ Alcohols (No conditions) → $HCl$
4. Condensation Esterification w/ Phenols ($NaOH$ to make phenoxide ion) → $NaCl$
5. Condensation Reaction w/ Ammonia (No conditions) → Simple Amides + $HCl$
6. Condensation Reaction w/ Primary Amines (No conditions) → Subsituted Amides + $HCl$a
# Carboxylic Acids
1. AS content
2. Oxidation of methanoic (any ox agent + warm)/ethandioic ($KMnO_{4}$ + heat) → $CO_{2}+ H_{2}O$
# Amines
1. Formation: (Halogenalkanes #3)
2. Formation: Reduction of Nitriles or Amides ($LiAlH_{4}$ only) + things tysh
3. Primary Amine w/ halogenalkanes (heat) → Sec. Amine + $HCl$
4. Basicity reactions
5. Liberation from salts by a strong base (gentle warming usually done)
6. Acyl Chlorides (No conditions) → Subsituted Amines + $HCl$

4. Acidic Hydrolysis: dil $H_{2}SO_{4}$ + heat → carboxylic acid + simple/sub ammonium salt
